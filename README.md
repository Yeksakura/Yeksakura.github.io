# Yikai Xue — Academic Homepage

Source for [yeksakura.github.io](https://yeksakura.github.io/), a lightweight academic homepage built with semantic HTML, CSS, and vanilla JavaScript.

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Content

- Research profile and interests
- Selected publications
- Research experience and education
- Email, GitHub, and an accessible WeChat QR dialog

The site has no build step or external runtime dependencies.
